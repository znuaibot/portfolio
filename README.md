# Portfolio — 陈维 / Chen Wei

个人作品集主页，使用 Three.js 构建全页面 3D 沉浸式体验。

## 特性

- 🎨 全页面 3D 场景，滚动驱动相机穿行
- 🖱️ 指针视差 + Dock 导航弹性放大
- 🌐 中英文一键切换（i18n）
- 📱 响应式设计，支持移动端
- ♿ 支持 `prefers-reduced-motion`
- 📦 单 HTML 文件，零外部运行时依赖

## 技术栈

- Three.js r149（本地化）
- 自定义 GLSL Shader
- 纯 CSS 动画
- 原生 JavaScript（无框架）
